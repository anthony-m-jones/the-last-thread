dialogue/  — CONVERSATIONS LIVE HERE (as .dialogue text files)
=============================================================

We use the "Dialogue Manager" addon (by Nathan Hoad). Conversations are written
in plain-text ".dialogue" files that you can edit like a script — no code.

Each conversation has a TITLE (a line starting with "~", e.g. "~ start") and
the lines beneath it. Scripts in this game only ever say "play the conversation
called X" and "do something when it ends" — they never contain the words the
cats say. That writing lives here so you can edit it freely.

Placeholder .dialogue files will be added in a later build step. You will paste
the real writing from the design doc into them.
